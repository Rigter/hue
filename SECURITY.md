# Security policy

## Supported versions

Security fixes are applied to the latest released version of `hue` and to the
default branch before the first release.

## Reporting a vulnerability

Please do **not** report security vulnerabilities in public GitHub issues.
Instead, use GitHub's private vulnerability-reporting flow:

<https://github.com/rigter/hue/security/advisories/new>

Include a description of the issue, affected versions, reproduction steps, and
any suggested mitigation. You can expect an acknowledgement within 7 days.

If private reporting is unavailable, contact the repository maintainer through
GitHub and avoid publishing exploit details until a fix is available.
